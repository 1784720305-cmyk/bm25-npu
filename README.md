## 先理解这一步

输入是每条记录的词频TF、文章长度项、IDF；设备计算 `IDF * (TF * 2.2) / (TF + 长度项)`，固定k1=1.2，输出每条记录的贡献。每个线程写不同输出，不涉及文章总分的并发累加。

这些展开输入便于第一次核对公式。后续完整查询接回稀疏倒排数组；如果由CPU展开输入，正式完整查询计时必须包含展开工作。

## 向MT解释关键函数

- ContributionSimt：每个线程读取记录，用自研公式算贡献。
