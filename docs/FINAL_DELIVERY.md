# 最终交付说明

最终内核为Warp Append正分ID直接追加、寄存器精确阈值选择、严格同分收集、原32路分级Merge。叶宽8192，256线程，显式UB50848字节、动态UB64KiB；容量1024，溢出走完整精确回退，不能截断。FP32按原查询词顺序累加，重复词保留；排名为分数降序、同分全局ID升序。

倒排按词组织：INT64边界、INT32文章ID、FP32 TF/norm/IDF。全词目录保存每词跨叶块的绝对倒排位置，V×(S+1)×8字节，独立于本次查询。索引常驻，每次只传查询包；评分融合局部Top-K，各级合并不回主机，最后回传Q×K分数/ID。

大库使用更多固定宽叶块和分级Merge，不扩大单块UB。千万篇1221叶，列表1221→39→2→1。仍限制65536叶、K1..32、Q<=10000、Q×补齐文档数<=INT32_MAX、倒排数<=INT32_MAX和实际预算；性能证据只覆盖Q8/3词/K10。
